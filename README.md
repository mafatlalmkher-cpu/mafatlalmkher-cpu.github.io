# Mafatlal M. Kher portfolio

A static personal portfolio covering plant biotechnology, plant virology, research, academic experience, education, publications, teaching, and research software.

## Publish on GitHub Pages

1. Create the repository `mafatlalmkher-cpu.github.io` under the `mafatlalmkher-cpu` account.
2. Upload the contents of this folder to the root of the `main` branch, including the PDF and `.nojekyll` file. Do not upload the enclosing folder or ZIP archive.
3. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
4. Wait for the Pages deployment to finish. The intended address is `https://mafatlalmkher-cpu.github.io/`.

This address becomes live only after a successful GitHub Pages deployment.

## Update the portfolio

- Update the career, project, education and service content in `index.html`.
- Replace `Mafatlal_Kher_CV.pdf` when the CV changes, keeping the filename stable so existing links still work.
- Publication records appear in the website source. Keep the publication count and any downloadable CV consistent when adding records.
- Styling is in `styles.css`; interactive controls are in `app.js`.

No package installation, build step, database, or API key is required.

## Content

The published files contain curated professional information. Supporting certificates, raw research data, unpublished manuscripts, identity documents, private reference contacts and original source documents are not part of this website.

GitHub guidance: [Creating a Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) and [Configuring the publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
